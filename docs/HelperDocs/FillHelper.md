**Fill Helper Working**
Fill Request
      │
      ▼
Wait Visible
      │
      ▼
Wait Enabled
      │
      ▼
Scroll Into View
      │
      ▼
Clear Existing Value
      │
      ▼
Fill Value
      │
      ▼
Verify Value
      │
      ▼
Success Log
      │
      ▼
Failure → ErrorHandler

**Public API**
await FillHelper.fill(locator, "Deepak");
